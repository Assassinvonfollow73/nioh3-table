How it works

Three steps to a fully unlocked save

No installers, no background services, no launcher. Just Cheat Engine and one table file.

1

Install Cheat Engine

Grab the latest Cheat Engine build from its official site and install it on Windows 10 or 11. The trainer table requires version 7.4 or newer.

2

Load the nioh3-table file

Launch Nioh 3, open Cheat Engine, and drag the downloaded .CT table into the window — or use File → Open. Attach to the nioh3.exe process when prompted.

3

Toggle your cheats

Check the boxes for Infinite HP, Infinite Ki, Max Amrita, One-Hit Kill, and the item and stat editors. Changes apply instantly and persist until you uncheck them.
